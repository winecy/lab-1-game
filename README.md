Задание

Мы начинаем писать ядро нашей игры. 
В этой лабораторной мы реализуем внутриигровое время и инвентарь (рюкзак) персонажа (пока без самого персонажа).



В начале программы инициализируйте:


Переменную current_day (тип int, значение по умолчанию 1).
Переменную current_hour (тип int, значение по умолчанию 8 – утро).



Статический массив inventory на 10 элементов (тип int, все элементы изначально равны 0). В этом массиве числа будут обозначать ID (идентификаторы) предметов: 
0 – пусто, 
1 – дерево, 
2 – камень, 
3 – семена,
4-9 – придумать самостоятельно;
Разложите предметы в инвентарь заранее, наиболее подходящим для вашего варианта образом.





Реализуйте текстовое меню со следующими пунктами: 

[0] Выход 
Завершает работу программы.

[1] Посмотреть на часы 
Выводит на экран текущий день и час в формате: "Текущее время: День 1, 08:00".

[2] Промотать время (Поработать) 
Запрашивает у пользователя, сколько часов он хочет потратить на работу. Прибавляет введенное значение к current_hour. 
Если значение часов превышает или равно 24, необходимо корректно перевести время на следующий день (или несколько дней), остаток часов записать в current_hour. 
Пример: было 20:00. Игрок поработал 6 часов. Стало: День 2, 02:00.

[3] Посмотреть инвентарь 
С помощью цикла (какого? думаем сами)  программа должна пройтись по массиву inventory и вывести содержимое слотов. Пример вывода: Слот 0: [0], Слот 1: [1] (Дерево) ...

[4] Положить предмет в слот 
Программа запрашивает индекс слота (от 0 до 9) и ID предмета. 
Значение записывается в массив по указанному индексу. 
Не забудьте проверить, что введенный индекс не выходит за границы массива!

[5] Выбросить предмет 
Программа запрашивает индекс слота и обнуляет его (записывает туда 0).

[6] Выполнить задание по варианту 
Выполняет специфичную обработку массива инвентаря согласно вашему варианту.

Инверсия карманов
Не используя других (дополнительных) массивов, перевернуть инвентарь задом наперед (элемент 0 меняется с 9, 1 с 8 и т.д.). Вывести инвентарь до и после преобразования.
